BYOT выполнен: consumer payload/reference/input/query/identity/output/claim key generic; Scope/Decision являются небольшими host/runtime envelopes. Core не зависит от ai-libs, network/credentials/telemetry. Нет scheduler, IAM engine, model provider или vector DB. Runtime envelopes не подменяют caller domain types обязательным map.

Record-level access выполняет Authority по exact record scope (host может split records); field profile сознательно unsupported. Search metadata никогда не становится canonical payload. Typed snapshots/exports не дают historical read обойти current revocation. Revocation/receipts content-free; forensic erasure и unmanaged copies не обещаются. Внешний authority/source/storage provisioning принадлежит host; нет exactly-once произвольного callback side effect. SQLite profile реально durable atomic/CAS, memory profile явно nondurable. Scoped decisions rechecked, но arbitrary external authority требует lease для cross-system atomic revoke.
